# Dave's Automotive Demo

A mobile-first website concept for Dave's Automotive, built around the business's mobile mechanic positioning and existing black/red/cream visual identity.

## Demo focus
- Mobile mechanic positioning
- Service discovery
- Local service area
- Request-service CTA
- Instagram contact path
- Customer review placeholder
- Responsive mobile-first layout

## Before launch
Replace the demo form handler with the client's real booking/contact workflow, add verified customer reviews, confirm the exact service area, and add the client's approved photography and contact details.

## Run
This is a static site. Open `index.html` locally or deploy the repository to Vercel as a static project.
